Investigation Summary

Run an investigation to see results here. This can take up to a minute — the LLM is calling MCP tools to gather evidence before synthesizing a result.

What this system does not claim: it does not identify root causes, predict failures, or assert that a deployment caused an incident. It surfaces correlated evidence — code changes, dependency reachability, runtime telemetry, and similar past incidents — for an engineer to interpret.
